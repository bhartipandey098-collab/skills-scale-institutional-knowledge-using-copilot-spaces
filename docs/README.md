# OctoAcme Project Management Docs

This repository centralizes the project management process documents used by OctoAcme. The pages below cover the standard lifecycle and operating rhythm for planning, delivery, risk management, and continuous improvement.

## Project management process summary
- Initiate work with a clear business problem, stakeholders, success metrics, and a decision gate.
- Plan scope, milestones, backlog, dependencies, and definition of done.
- Execute through team rituals, tracking, testing, and escalation paths.
- Manage risks and stakeholder communication with regular updates and clear ownership.
- Release with a structured deployment checklist and rollback plan.
- Close projects with retrospectives and action tracking for continuous improvement.
